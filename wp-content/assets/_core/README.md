Foleo Assets Core
=================

Purpose
- Shared engine assets used by all sites.
- Do not put site-specific styles here.

Edit Rules
- Default edits go in this folder.
- Site-specific overrides belong in:
  - /wp-content/assets/<namespace>/Brand.css
  - /wp-content/assets/<namespace>/Theme.css
  - /wp-content/assets/<namespace>/Theme.js
  - /wp-content/assets/<namespace>/nav-registry.json

Legacy
- Old per-site copies of core files were renamed to OLD_* and should not be edited.
